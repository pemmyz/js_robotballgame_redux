# JS Robot Ball Game 2.5D

A fast-paced 2.5D JavaScript physics sports game where two robot players
compete to score goals using a rolling ball, powered by **Planck.js**
(Box2D).

## 🚀 Features

-   2-player competitive gameplay (Blue vs Green)
-   AI modes for both robots: **None**, **Default**, **Defensive**,
    **Aggressive**
-   Sprint & stamina system with UI bars
-   Catch/hold ball mechanic with directional control
-   Dark/Light mode toggle
-   Touch controls for mobile
-   Real-time score, playtime, and round timer
-   Smooth 2.5D rendering with shadows

## 🎮 Controls

### **Player 1 (Blue)**

-   Move: **Arrow Keys**
-   Sprint: **N**
-   Catch: **M**

### **Player 2 (Green)**

-   Move: **W A S D**
-   Sprint: **V**
-   Catch: **B**

### Global

-   **P** -- Pause\
-   **H** -- Show help\
-   **1 / 2** -- Cycle AI mode for Player 1 / Player 2

## 📱 Mobile Controls

Both players have on-screen: - D-pad for movement - Sprint button -
Catch button

## ⚙️ Technologies Used

-   **HTML5 Canvas**
-   **JavaScript + Planck.js Physics**
-   **CSS3 (Dark/Light themes)**
-   Responsive design with mobile support
